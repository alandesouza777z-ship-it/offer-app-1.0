Importação em lote

Subir vários anúncios Meta por JSON

JSON de entrada

Cole um array JSON. Campos mínimos: adTitle, brandName, niche, promise, adLibraryUrl.

Formato recomendado

Modelo base

[
  {
    "adTitle": "Creatina Clean Performance",
    "brandName": "VitalForge",
    "niche": "Suplementos",
    "promise": "Ganhar força e consistência sem complicar a suplementação",
    "adLibraryUrl": "https://www.facebook.com/ads/library/"
  }
]
Cole seu JSON e rode a importação. Duplicatas por URL da Ad Library serão ignoradas.

Importação própria

Subir anúncios na biblioteca inferior

JSON da biblioteca

Campos mínimos: offerTitle, brandName, libraryUrl e adsCount >= 200.

Formato recomendado

Modelo base

[
  {
    "offerTitle": "Creatina Clean Performance",
    "brandName": "VitalForge",
    "libraryUrl": "https://www.facebook.com/ads/library/?id=706455939160239",
    "creativeUrl": "https://images.unsplash.com/photo-1517836357463-d25dfeac3438?auto=format&fit=crop&w=1200&q=80",
    "adsCount": 334
  }
]
Cole seu JSON e rode a importação para abastecer a biblioteca independente.
